群发助手 · Group Poster

一个 Chrome 扩展：把你写好的帖子，按随机间隔逐个发到你已加入的 Facebook 群组，也可以定时自动发。
A Chrome extension that posts to the Facebook groups you've joined, one by one with random delays, on a schedule if you like.

  • 定时排程：一次、每天、每周、每月 · Schedules: once, daily, weekly, monthly
  • 一键识别已加入的群组 · Find the groups you've joined
  • 文案变体，让每个群的帖子略有不同 · Text variations so each group gets a slightly different post
  • 测试模式、每日上限、遇到警告自动暂停 · Test mode, daily limit, auto-pause on warnings
  • 所有数据只保存在你自己的浏览器 · All data stays in your own browser
